# Drag Counter App

A beautiful, modern Progressive Web App (PWA) that allows users to increment or decrement a counter by dragging a button left or right.

## Features

- 🎨 **Modern Design** - Glass morphism UI with animated gradients
- 📱 **PWA Support** - Install as a native app on any device
- 🎯 **Drag Interaction** - Intuitive drag-to-count functionality
- 📱 **Responsive** - Works perfectly on desktop and mobile
- ⚡ **Offline Ready** - Service worker for offline functionality
- 🎭 **Smooth Animations** - Premium animations and transitions

## How to Use

1. **Drag Right** → Increase counter (+1)
2. **Drag Left** → Decrease counter (-1)
3. **Install** → Click the install button in your browser to add to home screen

## Installation

### As a Web App
Visit the live demo and click the install button in your browser's address bar.

### Local Development
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/drag-counter-app.git

# Navigate to project directory
cd drag-counter-app

# Serve locally (Python)
python -m http.server 8000

# Or use any other local server
# Then visit http://localhost:8000
```
